# Data Directory Structure

This directory contains datasets and trained models for Clean-GS.

## Expected Structure

```
data/
├── datasets/
│   └── [scene_name]/              # e.g., temple, isha
│       ├── images/                # Input images from camera views
│       │   ├── 000000.jpg
│       │   ├── 000001.jpg
│       │   └── ...
│       ├── sparse/0/              # COLMAP sparse reconstruction
│       │   ├── cameras.bin        # Camera intrinsics
│       │   ├── images.bin         # Camera extrinsics
│       │   └── points3D.bin       # Sparse point cloud
│       ├── cameras.json           # Camera parameters (generated by colmap_to_json.py)
│       └── masks/                 # Semantic segmentation masks
│           ├── 000000.png         # Binary mask for image 000000
│           ├── 000001.png         # Binary mask for image 000001
│           └── ...                # 3-5 masks recommended
└── models/
    └── [scene_name]/              # Trained 3D Gaussian Splatting models
        └── point_cloud/
            └── iteration_30000/   # Standard 3DGS output location
                └── point_cloud.ply  # Input for Clean-GS
```

## How to Populate This Directory

### Step 1: Capture Images

Capture multi-view images of your scene:
- Use 100-300 images from different viewpoints
- Ensure good overlap between views
- Maintain consistent lighting

### Step 2: Run COLMAP

Use the provided script to run COLMAP reconstruction:

```bash
bash scripts/run_colmap_temple.sh
```

Or manually run COLMAP:

```bash
colmap feature_extractor \
    --database_path data/datasets/YOUR_SCENE/database.db \
    --image_path data/datasets/YOUR_SCENE/images

colmap exhaustive_matcher \
    --database_path data/datasets/YOUR_SCENE/database.db

colmap mapper \
    --database_path data/datasets/YOUR_SCENE/database.db \
    --image_path data/datasets/YOUR_SCENE/images \
    --output_path data/datasets/YOUR_SCENE/sparse
```

### Step 3: Train 3D Gaussian Splatting

Train a 3DGS model using the [official implementation](https://github.com/graphdeco-inria/gaussian-splatting):

```bash
python train.py -s data/datasets/YOUR_SCENE -m data/models/YOUR_SCENE
```

This produces `point_cloud.ply` at:
```
data/models/YOUR_SCENE/point_cloud/iteration_30000/point_cloud.ply
```

### Step 4: Generate Semantic Masks

Use [Segment Anything (SAM)](https://github.com/facebookresearch/segment-anything) to create masks:

1. Install SAM:
   ```bash
   pip install git+https://github.com/facebookresearch/segment-anything.git
   ```

2. Download SAM checkpoint:
   ```bash
   wget https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth
   ```

3. Generate masks for 3-5 views:
   - Select diverse camera viewpoints
   - Segment the object of interest
   - Save as binary PNG masks (white = object, black = background)
   - Name masks to match image names (e.g., `000000.png` for `000000.jpg`)

**Tip**: You only need 3-5 masks (1% of views) for effective floater removal.

### Step 5: Convert Camera Parameters

Convert COLMAP cameras to JSON format:

```bash
python scripts/colmap_to_json.py \
    --colmap_path data/datasets/YOUR_SCENE/sparse/0 \
    --output_json data/datasets/YOUR_SCENE/cameras.json
```

### Step 6: Run Clean-GS

```bash
python clean-gs.py \
    --scene YOUR_SCENE \
    --masks_dir data/datasets/YOUR_SCENE/masks \
    --input_ply data/models/YOUR_SCENE/point_cloud/iteration_30000/point_cloud.ply \
    --output_ply data/models/YOUR_SCENE/point_cloud/iteration_30000/clean.ply
```

## Example: Temple Dataset

The Temple dataset from [Tanks and Temples](https://www.tanksandtemples.org/) is a good starting point:

```
data/datasets/temple/
├── images/          # 302 images (1920x1080)
├── sparse/0/        # COLMAP reconstruction
├── cameras.json     # Generated camera parameters
└── masks/           # 3 masks (1% of views)
    ├── 000050.png
    ├── 000150.png
    └── 000250.png
```

Original model: 526K Gaussians, 125 MB  
Clean-GS output: 198K Gaussians, 47 MB (62% reduction)

## File Formats

- **Images**: JPG or PNG
- **Masks**: PNG (binary: 0 = background, 255 = object)
- **COLMAP**: Binary format (`.bin` files)
- **cameras.json**: JSON with camera parameters
- **point_cloud.ply**: PLY format with Gaussian parameters

## Data Not Included

Due to size constraints, the data directory is not included in the repository. You must:
1. Download or capture your own datasets
2. Run the preprocessing pipeline
3. Train 3DGS models
4. Generate semantic masks

## Gitignore

The following are excluded from git tracking:
- `data/datasets/*` (can be very large)
- `data/models/*` (models are 100+ MB)
- `*.ply` files (point clouds)
- `*.bin` files (COLMAP outputs)

## Storage Requirements

Typical storage per scene:
- Images: 1-5 GB (depending on resolution and count)
- COLMAP sparse: 10-100 MB
- 3DGS model: 100-500 MB
- Masks: 1-10 MB (only 3-5 masks needed)

**Total**: 1-6 GB per scene
